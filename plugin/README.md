# Autoroute plugin for Claude Code

Picks the Claude model and effort for each task. It needs the local Autoroute service:

```bash
npm install -g https://github.com/rabbit-roger/autoroute/archive/refs/heads/main.tar.gz
autoroute setup
```

Then type `/autoroute-on` in a conversation. See the [main README](https://github.com/rabbit-roger/autoroute#readme).
